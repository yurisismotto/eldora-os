# Eldora OS

> Simple. Powerful. Yours.

Eldora OS is a project exploring a modern desktop platform built on the
Linux kernel.

Eldora OS is intended to be an open-source project. Licensing is pending: no
license has been selected, and this repository is not yet published under an
open-source license.

No production operating-system implementation exists yet.

## Important

Architectural recommendations are not decisions.

Permanent architectural decisions must be explicitly approved by the Project
Owner and recorded through the project's Architecture Decision Record (ADR)
process. Governance, legal/licensing and brand/trademark decisions are
recorded in their own decision records.

The Git repository is the source of truth for project knowledge.
