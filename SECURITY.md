# Security Policy

Eldora OS is currently in its Foundation phase (Wave 0) and has no releases
and no production implementation.

## Reporting status

**No private vulnerability reporting channel exists yet.**

The project is not yet able to receive security reports confidentially.
Before the project accepts security reports, the Project Owner must
configure an appropriate private reporting mechanism and document it here.
Defining the disclosure process and reporting channel is tracked as Q-0012
in the [Decision Register](docs/adr/DECISION-REGISTER.md) (Wave 0.6).

Until a private channel is documented here:

- do not disclose suspected vulnerabilities publicly, including in public
  issues, pull requests or discussions;
- do not include exploit details in any public project space.

## Supported versions

No versions are supported. A supported-version policy will be defined
before production releases.

## Principle

Security must not be weakened merely for implementation convenience.
