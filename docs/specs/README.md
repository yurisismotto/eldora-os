# Specifications

SPECs define sufficiently complex behavior before implementation.

A SPEC must not silently introduce architectural decisions that should be
represented by an ADR.

- File naming: `docs/specs/SPEC-NNNN-<slug>.md`, using
  [`SPEC-TEMPLATE.md`](SPEC-TEMPLATE.md).
- SPEC states: `DRAFT`, `IN REVIEW`, `APPROVED`, `REOPENED`, `SUPERSEDED`,
  `WITHDRAWN`. Valid transitions are defined in
  [`../project/DECISION-LIFECYCLE.md`](../project/DECISION-LIFECYCLE.md).
