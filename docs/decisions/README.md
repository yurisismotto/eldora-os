# Non-architectural Decision Records

Architectural decisions are recorded as ADRs in [`../adr/`](../adr/).
Other decisions tracked in the
[Decision Register](../adr/DECISION-REGISTER.md) are recorded here, as small
and objective records. A non-architectural decision must not be turned into
an ADR merely to close a question.

| Question type | Record | ID | File |
|---|---|---|---|
| GOVERNANCE | Governance Decision Record | `GDR-NNNN` | `docs/decisions/GDR-NNNN-<slug>.md` |
| LEGAL / LICENSING | Project/Legal Decision Record | `LDR-NNNN` | `docs/decisions/LDR-NNNN-<slug>.md` |
| BRAND / TRADEMARK | Brand Decision/Status Record | `BDR-NNNN` | `docs/decisions/BDR-NNNN-<slug>.md` |

All three use [`DECISION-RECORD-TEMPLATE.md`](DECISION-RECORD-TEMPLATE.md).
States, transitions and links are defined in
[`../project/DECISION-LIFECYCLE.md`](../project/DECISION-LIFECYCLE.md).
Only the Project Owner may accept a record
([`../project/GOVERNANCE.md`](../project/GOVERNANCE.md)).
