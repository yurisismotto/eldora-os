# Architecture Decision Records

ADRs record explicit architectural decisions approved by the Project Owner.
ADRs are reserved for questions of type ARCHITECTURE in the
[Decision Register](DECISION-REGISTER.md). Governance, legal/licensing and
brand/trademark decisions use the records in
[`../decisions/`](../decisions/README.md), not ADRs.

Research and recommendations do not automatically become ADR decisions.

- File naming: `docs/adr/ADR-NNNN-<slug>.md`, using
  [`ADR-TEMPLATE.md`](ADR-TEMPLATE.md).
- ADR states: `PROPOSED`, `ACCEPTED`, `REJECTED`, `WITHDRAWN`,
  `SUPERSEDED`. Valid transitions, the Decision Register lifecycle and the
  `Q-xxxx → RES-xxxx → ADR-xxxx` links are defined in
  [`../project/DECISION-LIFECYCLE.md`](../project/DECISION-LIFECYCLE.md).
- Only the Project Owner can move an ADR to `ACCEPTED`, and only with
  `Approved by`, `Approval date` and `Approval evidence` filled in
  ([`../project/GOVERNANCE.md`](../project/GOVERNANCE.md)).

The Decision Register is kept in this directory during the Foundation phase;
it indexes questions of all types. Its location may be reconsidered later.
