`Approved by`, `Approval date` and `Approval evidence` are filled only when
the Project Owner accepts the ADR, by the Project Owner or at the Project
Owner's explicit, referenced instruction. Approval evidence must be a
verifiable reference, such as the Project Owner's commit that changes the
status or a record written by the Project Owner. An agent must not fill
these fields on its own initiative. See
[`../project/DECISION-LIFECYCLE.md`](../project/DECISION-LIFECYCLE.md).
