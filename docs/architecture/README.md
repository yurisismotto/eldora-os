# Architecture

This directory contains architecture documentation derived from ACCEPTED
ADRs.

Unapproved architecture proposals and research must not be presented here as
established architecture.

Accepted architecture decisions so far: [ADR-0001](../adr/ADR-0001-v1-base-composition-bootc-oci.md)
(V1 base-system composition). The consolidated V1 architecture baseline is
produced in Wave 0.5 from ACCEPTED ADRs. The current conceptual stack is a
working hypothesis only, recorded in
[`../project/CURRENT-STATE.md`](../project/CURRENT-STATE.md#working-hypothesis-conceptual-architecture).
It is validated or refuted in Wave 0.4 (Q-0004).
